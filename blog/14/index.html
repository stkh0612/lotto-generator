로또 용지의 보안 기술과 훼손 복권 구제 기준

로또 용지 우측 상단에는 정사각형 모양의 QR코드가 인쇄되어 있습니다. 스마트폰 카메라나 동행복권 앱으로 이 QR코드를 비추면 추첨 직후 즉시 당첨 여부와 등수가 화면에 나타납니다. QR코드의 작동 원리와 만약 복권이 훼손되었을 때 어떻게 대처해야 하는지 알아봅니다.

1. 로또 QR코드의 원리와 가짜 복권 구별법

로또 영수증의 QR코드에는 단순한 회차 정보뿐만 아니라 다음과 같은 암호화 데이터가 포함되어 있습니다.

  • 회차 번호
  • 발행 판매점 코드
  • 선택된 5개 게임(A~E)의 번호 데이터
  • 중앙 서버 검증용 위변조 방지 보안 키

동행복권 공식 서버 URL(`dhlottery.co.kr`)로 연결되는 이 QR코드를 스캔하면, 서버에 저장된 해당 복권의 고유 발행 기록과 대조하여 즉시 당첨 결과를 계산해 보여줍니다. 만약 누군가 포토샵으로 번호를 위조하여 인쇄하더라도, QR코드를 스캔하면 원본 발권 데이터가 나타나므로 위변조가 원천적으로 불가능합니다.

2. 복권이 찢어지거나 세탁기에 들어갔을 때 (훼손 기준)

바지 주머니에 로또 복권을 넣은 채로 세탁기를 돌려 종이가 젖고 찢어지는 사고가 종종 발생합니다. 당첨금을 받을 수 있을까요?

복권 및 복권기금법 시행령에 따른 당첨금 지급 기준은 다음과 같습니다.

- 지급 가능 조건 (1/2 이상 원형 보존 및 일련번호 식별):
1. 복권의 1/2 이상이 원형대로 보존되어 있어야 합니다.
2. 컴퓨터 판독이 가능한 바코드 또는 하단의 번호 일련번호(24자리 숫자)가 훼손되지 않고 명확히 식별되어야 합니다.
- 지급 불가 조건:
1. 일련번호와 바코드가 완전히 지워져 중앙 컴퓨터 데이터와 대조가 불가능한 경우.
2. 복권의 절반 이상이 유실된 경우.

3. 훼손 복권 처리 행동 요령

  1. 젖은 복권은 헤어드라이어로 급하게 말리지 말고, 그늘에서 자연 건조시키세요. (열로 인해 감열지 영수증이 검게 탈 수 있습니다.)
  2. 찢어진 조각들을 테이프로 억지로 붙이지 말고, 투명 비닐 팩에 모든 조각을 모아 담으세요.
  3. 고액 당첨 복권이 훼손된 경우, 일반 판매점이 아닌 농협은행 본점 또는 동행복권 본사를 방문하여 정밀 전산 감정(정밀 스캔 및 감열 분석)을 의뢰해야 합니다.
